# Amazon Image Requirements Reference

This reference captures baseline Amazon listing image requirements and the stricter local workflow for this workspace. Requirements can change by marketplace and category, so verify current Seller Central/category guidance for final upload-critical work.

## Main Image Baseline

- Use a pure white background: RGB 255, 255, 255.
- Show the actual product being sold.
- Product should fill about 85% or more of the image frame.
- Do not add extra text, graphics, badges, borders, watermarks, price tags, rating graphics, or promotional overlays.
- Do not show props or accessories unless they are included in the purchase.
- Use professional-quality imagery: sharp, well lit, accurate color, no pixelation.
- Use accepted formats such as JPEG/JPG, PNG, or TIFF where supported.
- Use RGB or CMYK color mode where supported by Amazon guidance.
- Use at least 1000 px on the longest side for zoom eligibility; this workspace uses 2K+ output by default.
- Amazon forum guidance also lists a maximum 10GB file size and says upload filenames should contain the product identifier, such as ISBN, UPC, EAN, or JAN, and end with an accepted extension.
- Avoid transparent backgrounds in final upload assets; flatten images onto the intended background.
- Show the full product clearly unless a close-up secondary image is intentionally focused on a detail.

## Secondary Image Baseline

Secondary gallery images can use more commercial design tools:

- Lifestyle scenes showing realistic use.
- Infographics with concise callouts.
- Size and scale charts.
- Feature close-ups.
- Before/after or comparison layouts when truthful and compliant.
- Use-step diagrams.
- Package or included-accessory images.
- Multiple angles: front, side, back, key detail, and product in use when useful.

Even for secondary images, do not exaggerate function, alter product appearance, invent included items, or make unsupported claims.

## Local Workspace Defaults

- Square listing image: 2000 x 2000 px.
- Vertical listing image: 1600 x 2000 px.
- No Amazon image output should be below 2K quality unless the user explicitly requests a smaller derivative.
- Preserve the provided product appearance exactly. Product deformation, wrong text, wrong color, altered function, or invented details make an output unusable.
- For final delivery, check pixel dimensions, visual fidelity, text legibility, claim safety, and main-image compliance before calling the image upload-ready.

## Compliance Notes

- Category rules can add restrictions beyond the baseline. Check category-specific Seller Central guidance when the product type is sensitive, regulated, apparel, supplement, medical, child/baby, food, electronics, or claims-heavy.
- Claims visible in images should be supportable. Avoid medical, absolute, ranking, guarantee, or comparative claims unless the user provides proof and marketplace suitability.
- Competitor references are for insight, not copying. Derive original layouts and copy.
